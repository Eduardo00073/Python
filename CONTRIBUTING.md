# Guia de Contribuicao

Obrigado por se interessar pelo python-fundamentos, colecao de aulas e exercicios de Python usados em sala de aula.

## Como contribuir

1. Faca um fork do repositorio.
2. Crie uma branch descritiva para sua alteracao.
3. Envie um Pull Request explicando o que foi mudado e por que.

## Sugestoes de contribuicao

- Novos exercicios para alunos iniciantes.
- Comentarios didaticos explicando a logica de cada script.
- Correcao de erros ou melhoria de exemplos existentes.

Toda contribuicao construtiva e bem-vinda!
