## 📖 Sobre o repositório

Este repositório reúne o material das minhas aulas de **Lógica de Programação e Python**, com scripts progressivos organizados em módulos temáticos que acompanham a evolução do aluno: desde a sintaxe básica até a construção de aplicações funcionais com interface gráfica e banco de dados.

---

## 🎯 Objetivo

Servir como material de apoio para turmas de Programação, reforçando conceitos como variáveis, estruturas condicionais, laços de repetição, funções, estruturas de dados e lógica de programação aplicada, sempre com exemplos práticos e projetos completos.

## ▶️ Como Usar

1. Escolha o módulo e o script desejado.
2. Execute com:
   ```bash
   python 01-introducao/hello_world.py
   ```
3. Para o App de Afazeres (projeto final com interface gráfica):
   ```bash
   python 06-projetos-praticos/app_afazeres/front_end.py
   ```
