## 📖 Sobre o repositório

Este repositório reúne o material das minhas aulas de **Lógica de Programação e Python**, com scripts progressivos que acompanham a evolução de um aluno: desde a sintaxe básica até a construção de pequenos programas funcionais.

Cada pasta `aulaX` representa uma aula/tema específico, contendo o(s) script(s) `.py` trabalhados naquele momento. Algumas aulas têm as versões `- inicio` (código de partida) e `- fim` (código final), facilitando o acompanhamento passo a passo durante a explicação em sala.

## 🗂️ Estrutura do repositório

- `aula3` a `aula32` — scripts individuais (`main.py`) de cada aula, com complexidade crescente
- `aula12 - prjContador` — mini projeto prático: um contador em Python (`contador.py`)
- Pastas com sufixo `- inicio` / `- fim` — versões de início e término do código trabalhado em determinadas aulas

## 🎯 Objetivo

Servir como material de apoio para minhas turmas de Programação, reforçando conceitos como variáveis, estruturas condicionais, laços de repetição, funções e lógica de programação aplicada, sempre com exemplos práticos.

## ▶️ Como usar

1. Escolha a pasta da aula desejada.
2. Execute o script principal com `python main.py` (ou o nome do arquivo correspondente).
3. Acompanhe os comentários no código para entender a lógica aplicada em cada exercício.
